# 💻 C# Object-Oriented Programming (OOP)

## 📌 About This Repository

This repository contains my C# practice programs and learning examples related to **Object-Oriented Programming (OOP)**.

OOP is a programming approach based on classes and objects. It helps organize code, improve reusability, and make applications easier to maintain.

## 🎯 Learning Objectives

- Understand the fundamentals of OOP in C#
- Learn classes and objects
- Implement inheritance and polymorphism
- Understand abstraction and encapsulation
- Practice OOP concepts with real-world examples

## 🛠️ Technologies Used

- C#
- .NET
- Visual Studio

## 📚 Concepts Covered

- Classes and Objects
- Constructors
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction
- Abstract Classes
- Interfaces
- Method Overloading
- Method Overriding
- Access Modifiers
- Virtual and Override Keywords
- Sealed Classes
- Static Members
- Properties

## 🌟 Key Benefits of OOP

- Code reusability
- Improved maintainability
- Better code organization
- Data security through encapsulation
- Flexibility and extensibility

## 🚀 Purpose

The purpose of this repository is to strengthen my C# programming fundamentals and gain practical knowledge of Object-Oriented Programming through hands-on examples.
